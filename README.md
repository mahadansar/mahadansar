[![license](https://img.shields.io/github/license/mahadansar/sol-luna-orchestrator?label=license)](https://github.com/mahadansar/sol-luna-orchestrator/blob/main/LICENSE)

An MIT-licensed MCP server for OpenAI Codex that lets a model-agnostic parent decide whether to work solo or delegate bounded tasks to isolated GPT-5.6 Luna workers, with reasoning effort selected per task.

- Supports single, sequential, and parallel delegation based on task structure
- Isolates parallel workers in Git worktrees with scope and integration-conflict detection
- Independently verifies worker results and compares claimed edits with observed changes
- Uses focused context handoffs, guided discovery, CLI diagnostics, and live activity observability
- Built with TypeScript and Node.js, distributed on npm, and tested on Windows, Linux, and macOS
